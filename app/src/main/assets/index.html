GPS : non démarré
Placez-vous sur le point, puis touchez « Mesurer ». Le GPS fait N mesures successives (≈ 1 par seconde) et en calcule la moyenne.
X = longitude, Y = latitude (degrés), Z = altitude GPS (approximative). Après chaque enregistrement, le numéro suivant est proposé automatiquement et vous le confirmez à la mesure suivante.
Les fichiers sont téléchargés ; si le téléchargement est bloqué, copiez le texte ci-dessous et collez-le dans un fichier.
Avec l’origine « Position GPS », les deltas se mettent à jour en marchant (nécessite des points en longitude/latitude). La flèche suit votre direction de marche dès que vous avancez ; à l’arrêt, le haut de l’écran est le Nord.
« Lire » ouvre le fichier sur la carte. Les fichiers sont conservés dans l’application ; pour les sortir du téléphone, utilisez Export ou Partager.
PocketGPSTools est arrêté
Le GPS est coupé et vos fichiers sont enregistrés. Pour fermer complètement l’application : geste ou bouton Retour/Accueil d’Android, ou balayez-la dans la liste des applications récentes.
